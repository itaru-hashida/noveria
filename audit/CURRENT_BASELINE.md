# Свежая проверка базового сценария

Запуск выполнен 4 ноября 2026 года на текущем состоянии репозитория, Python
3.12.15 и `ladybug==0.22.1`. Использован обычный движок без изменения правил:

```text
python audit/scenario_runner.py --seed 17 --months 36 --scenario baseline --out audit/_runs/current
python audit/scenario_runner.py --seed 2026 --months 36 --scenario baseline --out audit/_runs/current
```

Полные результаты: `audit/_runs/current/baseline_17.csv` и
`audit/_runs/current/baseline_2026.csv`. Они побайтно совпали с исходными
базовыми прогонами в `audit/_runs/`.

|---|---:|---:|
| Средний выпуск хлеба | 1576,51 | 1530,91 |
| Диапазон выпуска хлеба | 787,86–2278,04 | 567,63–2066,90 |
| Средний дефицит хлеба | 744,44 | 721,63 |
| Средний дефицит рыбы | 290,77 | 314,79 |
| Выпуск рыбы | 180 каждый месяц | 180 каждый месяц |
| Золото постоянно | да | да |
| Инварианты каждого месяца | да | да |

Следствие: наблюдаемые дефицит базовой еды и колебания выпуска хлеба
воспроизводятся на текущем коде. Эти два базовых прогона не устанавливают
единственную причину и не выбирают правило для изменения.

Проверка тестов в этой среде: 80 passed. Тесты запускались с временной папкой
внутри репозитория, поскольку системная временная папка pytest недоступна.
