# Noveria

Экономическая симуляция мира: государства, население, предприятия,
производство и торговля. Один ход соответствует месяцу.
Ядро написано на Python 3.12; будущий игровой клиент — Godot.
Streamlit оставлен для необязательного ручного просмотра.

## Навигация

- `main.py` — сборка приложения, `create_application()`.
- `core/world_service.py` — игровые действия и команды.
- `core/turn_service.py` — выполнение месячного хода.
- `core/db.py` — запросы к LadybugDB: структура мира и события.
- `core/economy_state.py` — экономика в памяти и Parquet-checkpoint.
- `modules/economy/` — правила торговли, производства и расчётов.
- `shadow/` — экспериментальное параллельное планирование.
- `content/` — исходные данные мира и параметры экономики.
- `tests/` — тесты; `scripts/` — CLI; `audit/` — диагностика.
- `docs/` — исследования и решения; `ui/` — отладочный интерфейс.

## Установка и проверка

Из корня репозитория, в виртуальном окружении Python 3.12:

    python -m pip install -r requirements.txt
    python -m pytest -q

Отдельный тест:

    python -m pytest -q tests/test_name.py

Запуск CLI и опционального UI описан в `README.md`.
Дополнительные зависимости: `requirements-research.txt` и
`requirements-ui.txt`.

## Как работать

- Сначала изучи код и тесты участка, к которому относится задача.
- Делай минимальное законченное изменение в пределах запроса.
- Для исправления ошибки добавь или обнови регрессионный тест.
- Запусти связанные тесты; перед передачей изменений — полный набор.
- В отчёте укажи результат, проверки и оставшиеся проблемы.
  Не объявляй проверенным то, что не запускалось.
- Сохраняй чужие незакоммиченные изменения.
- Python: четыре пробела, `snake_case`, классы — `PascalCase`.
  Комментарии и пояснения — по-русски.

## Границы архитектуры

- Ядро (`core/`, `modules/`) независимо от интерфейса.
- Игровые действия проходят через `WorldService`; запросы БД —
  через `core/db.py`.
- Экономика живёт в `EconomyState` между ходами; сохранение — Parquet.
  Полная экономика не перечитывается и не записывается в Ladybug каждый ход.
- `content/` не переписывается симуляцией.
- При изменениях расчёта проверяй деньги, товары, резервы и воспроизводимость.
  Порядок сделок и RNG влияют на результат.
- В экспериментальном multiprocessing workers считают планы;
  основной процесс применяет intents и меняет состояние мира.

Подробные документы читай по задаче. Историю исследований и результаты
замеров записывай в `docs/`, сохраняя этот файл коротким.
