# Первый рабочий Cython-участок: update_prices

Дата: 12.11.2026. База: `375c1e9`.

## Реализация

В Cython последовательно исполняются все ветви `update_prices()`:

- спрос из `meta.public_orders` и пределы цен покупателей;
- повышение и снижение по прошлым продажам;
- обзор конкурентов с учётом уже обновлённых цен ранних фирм;
- рыночный сигнал с компенсированным суммированием Python 3.12;
- ветвь `price_feedback`;
- ограничения minimum/maximum price.

Native-вход состоит из плоских массивов. В вычислительном цикле нет engine,
объектов фирм, dict, callback или RNG. Маршрутные расстояния получены исходным
Python `path()` во время pack. Apply лишь записывает price/ask_price journal.
Версии и игровые кэши участок не меняет; производные Python-кэши не имитируются
и при последующем обращении перестраиваются старым кодом.

## Проверка точности

На одинаковых состояниях сравнивались Python `update_prices()` и
`pack → Cython → apply`, затем полный старый V3 против native-режима.
После каждого месяца проверялись accounts, enterprises, meta, report, RNG и
`validate()`, включая заявки, сделки, проекты, склады и резервы.

- 1 месяц, seed `73129`: совпало;
- 12 месяцев, seed `73129`: совпало;
- 12 месяцев, seed `17`: совпало;
- первое расхождение: отсутствует.

Команда повторной проверки:

```bash
python audit/native_update_prices.py --seed 73129 --months 12
```

## Замер без cProfile

Seed `73129`, `detail=none`, два прогретых месяца, четыре пары ABBA на одном
checkpoint. Создание checkpoint не входит в замер; pack/apply входят.

| Участок | Медиана | Диапазон |
|---|---:|---:|
| старый `update_prices` | 16,074 мс | 15,439–16,571 мс |
| pack | 5,919 мс | 5,555–6,179 мс |
| Cython call | 0,161 мс | 0,154–0,172 мс |
| apply | 0,176 мс | 0,153–0,221 мс |
| полный V3 step | 476,349 мс | 292,313–497,298 мс |
| полный native step | 473,967 мс | 300,754–484,048 мс |

Разность медиан полного хода: 2,382 мс в пользу native. Это не отдельный
50-мс результат: главная цена границы — pack, а не вычисление.

## Сборка

Linux-проверка: Python 3.12.12, Cython 3.3.1, GCC 12.2.0.

```bash
python -m pip install -r requirements-native.txt
cd modules/economy/native
python setup.py build_ext --inplace
```

Импорт и вызов с typed arrays прошли. Windows/MSVC в доступной среде
отсутствуют, поэтому Windows-сборка не выполнялась и не считается проверенной.
Платформенно специфичные GCC-флаги в setup.py отсутствуют.
