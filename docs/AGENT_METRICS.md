# Метрики поведения агентов Noveria

Цель — найти странное поведение, объяснить его и проверить исправление. Метрика
сама по себе не является целевой функцией игры. Код расчёта —
`scripts/research_agents.py`; он наблюдает V3, не изменяя игровой движок.

## Протокол исследования

Базовая ревизия: `e1fa27d`. Три мира существующего сценария: seeds 73129, 17,
2026. Из состояний месяца 180 выполняются 60 следующих ходов. Контрольная серия
сверяется с ранее рассчитанными состояниями месяца 240: счета, предприятия,
EconomyMeta и RNG должны совпадать. Все эксперименты начинают с тех же снимков.
Контрольные состояния содержат RNG; наблюдатель не делает случайных выборов.
Вмешательства могут изменить дальнейшее число RNG-вызовов: общая начальная
случайность не означает неизменность каждой последующей очереди.

Варианты:

1. `control`: только наблюдение.
2. `input_bid`: перед закупкой сырья разрешено повысить оценочный лимит до
   текущей котировки, но не выше свободного бюджета и предельной цены входа,
   сохраняющей неотрицательную ожидаемую маржу при зафиксированной оценке чистой
   цены выпуска. Другие входы оцениваются не ниже ранее принятых обязательств.
   Количество и выпускной план не увеличиваются, зарплата и прочие резервы
   сохраняются. Это экспериментальная политика, не готовая правка игры.
3. `shock`: в относительных месяцах 7–12 нулевые потребности населения и личные
   покупки владельцев; с месяца 13 исходные настройки полностью возвращаются.
   Изменяются существующие ставки потребностей на ноль, ключи товаров остаются.

Первичная оценка эффекта `input_bid` — среднее удовлетворение базовой корзины
населения в относительных месяцах 31–60. Корзина взвешена фиксированными
стартовыми ценами; это индекс физических потребностей, не текущие расходы.
Вторичные показатели — хлеб, воспроизводство по товарам, деньги, прибыль,
неисполненные заявки, инвестиции и инварианты. Порог восстановления после шока:
трёхмесячное среднее потребления хлеба не ниже 90% соответствующего контроля,
условие выполнено на трёх последовательных наблюдениях. Срок отсчитывается с месяца 13;
невосстановление за 48 месяцев — цензурированное наблюдение, не нулевой лаг.

Статистическая единица — мир. Для трёх разностей между парными сериями считается
точная двусторонняя перестановка знаков средних эффектов. Минимально возможное
p при n=3 — 0.25: малые p нельзя получить, объявив месяцы независимыми опытами.
Это разведочное исследование трёх выбранных миров одного генератора, не
подтверждающее испытание на распределении всех возможных карт. Знаки эффектов,
диапазон и масштабы важнее фиктивной точности. Вторичные показатели не объявляются
отдельными значимыми открытиями по десяткам p-value.

## Шесть макроблоков

После просмотра контрольного распределения денег добавлен разведочный вариант
`cash_return`: ежемесячный возврат владельцу всей кассы сверх рабочего и проектного
резервов, после обычных дивидендов. Денег и кредитов не создаётся, защищённые
обязательства сохраняются. Его проверка вторична и выбрана по данным; она не
выдаётся за заранее заявленный первичный тест. Для этого варианта сохранена
отдельная версия наблюдателя, хеши версий есть в metadata.json; контрольная
экономическая логика в обеих версиях одинакова. При рассмотрении двух
проверок вместе применяется поправка Holm, а не выбор меньшего p-value.

| Блок | Расчёт | Ограничения |
|---|---|---|
| Торговля | Оборот = сумма цены товара и доставки по реальным сделкам; скорость = оборот / денежная масса; исполнение заявок отдельно по товарам | Налог не добавляется второй раз; одинаковое золото может участвовать в нескольких сделках |
| Воспроизводство | По каждому товару: выпуск / (потребление + производственные входы + стройматериалы), изменение склада, план и мощность | Нулевой выпуск при расходовании запаса не равен вымиранию; тонны разных товаров не складываются в показатель благополучия |
| Деньги | Доли секторов; доля денег на счетах без исходящих проводок минимум шесть наблюдаемых месяцев | Отсутствие расходов не доказывает недоступность капитала; первые пять месяцев оценки простоя — N/A |
| Дефициты населения | Потреблено / нужно по товару и фиксированно взвешенной базовой корзине; личное потребление владельцев отделено | Потребность, денежная заявка и обеспеченный неудовлетворённый остаток — разные величины |
| Прибыль | Сумма учётной прибыли и доля фирм с выручкой, продающих с убытком; зарплаты отдельно | Себестоимость проданных запасов и затраты нового выпуска признаются в разные моменты |
| Строительство | Числа стартов, завершений и отмен; незавершённые проекты; сроки без прогресса; стоимость закреплённых материалов / всех запасов | Завершения текущего окна могут относиться к старым проектам, поэтому built/started не называется когортным success rate |

Запасы сравниваются в фиксированных стартовых ценах. Денежная масса и резервы
не являются отдельными деньгами; резервы нельзя прибавлять к балансам.

## Пятнадцать микрометрик

Все показатели имеют узкую проверяемую область. Прочерк/N/A означает отсутствие
знаменателя или необходимых данных; он не заменяется хорошим нулём.

| Метрика | Операциональное определение |
|---|---|
| Signal Coverage | При закупочном планировании фирмы: известные IDs опубликованных за месяц достижимых buy своего товара / все такие IDs за месяц. Финальная публикация проверяется после торгов. Это видимость опубликованных заявок, не всей физической потребности и не доля спроса, которую фирма вправе присвоить |
| Signal Freshness | Доля вызовов ценового ориентира при закупочном планировании, использующих живые предложения; отдельно исторические цены с возрастом 1–3 месяца, взвешенным торговым объёмом. Стартовый ориентир без наблюдения — отдельная категория prior с неизвестным возрастом |
| Signal Accuracy | Среднее `1 - abs(L0-Lt)/max(L0,Lt,EPS)`: начальная предельная оценка цены заявки против котировки на её количество непосредственно перед исполнением. Это точность оценки очереди и ценовой лестницы, не оценка истинной скрытой ценности |
| Signal Response Rate | Доля изменений плана в направлении изменения доступного спроса среди событий со сдвигом спроса >10%, положительной маржой, прежним планом внутри мощности, неизменной мощностью, малым сдвигом склада (≤10% мощности) и кассой, покрывающей итоговый план. Фильтры снижают смешение, но не исключают все денежные ограничения и не делают показатель причинным |
| Response Elasticity | Медиана `Δlog(1+план)/Δlog(1+спрос)` на той же выборке; отдельные значения, число событий и разброс обязательны. Нулевая реакция на насыщенной мощности не называется ошибкой |
| Decision Consistency | Совпадение двух повторных чистых production_outlook и неизменность RNG. Проверяются до 10 первых пригодных решений каждые 10 месяцев; это выборка, не утверждение о всех возможных состояниях |
| Feasibility Rate | Доля окончательных планов, покрытых кассой, зарплатой и денежными обязательствами закупок. Отдельно проверяется индивидуальный предел мощности, местного труда и ресурса. Совместное снабжение всех фирм не предполагается — его проверяет исполнение |
| Decision Regret | Условная упущенная маржа обнаруженной локальной альтернативы закупке сырья. Альтернатива должна иметь реальный доступный товар, деньги вне других обязательств, оплачиваемую зарплату, остальные входы в наличии и достаточные индивидуальные труд/ресурс/план. Цена будущего выпуска зафиксирована на момент решения. Это ex ante свидетель, не фактически гарантированная прибыль и не глобальный оптимум |
| Dominated Decision Rate | Закупочные решения с таким свидетелем / все исполненные попытки закупок сырья. Свидетель лучше отказа при зафиксированной прогнозной цене; будущий рынок не известен |
| Execution Fidelity | По каждому товару: фактический выпуск / окончательный план, отдельно причины недовыпуска. Исполненные покупки и завершённые стройки показываются отдельно |
| Invariant Violation Rate | Нарушенные проверки / выполненные проверки и число неуспешных ходов. Падение расчёта фиксируется как failed, а не как отсутствие наблюдения |
| Missed Feasible Trade Rate | Доля попыток match, оставивших сделку с реальным остатком, маршрутом, ценой внутри действующего лимита и достаточным резервом. Прибыльные сделки выше лимита относятся к качеству решения, а не к поломке matcher |
| Adaptation Lag | Лаг устойчивого восстановления хлебного потребления после описанного шока относительно парного контроля. Показываются первое пересечение и устойчивое восстановление; невосстановившиеся случаи цензурированы |
| Forecast Improvement | `1 - MAE_model/MAE_naive` на ограниченной выборке: прогноз t против собственных продаж t+1, наивный прогноз — продажи t. Ошибки нормированы мощностью. Исключаются распроданные/недостаточные предложения: продажи при дефиците — цензурированный спрос. Доля исключённых и N показаны; нулевая ошибка naive даёт N/A |
| Persistent Regret | Фирмы с локальным свидетелем минимум три месяца подряд, доля среди фирм с закупками, максимальная серия. Это устойчивость конкретной упущенной возможности, не накопленный глобальный regret |

Локальные альтернативы разных решений могут конкурировать за один товар.
Сумма их условных выгод не является совместно достижимой прибылью экономики.
Глобальный regret, истинная эластичность предпочтений и полный оптимальный
инвестиционный портфель по этим данным не идентифицируются. Инвестиции и стройки
здесь оцениваются по потокам, доступной мощности, срокам и исполнению. Независимые
оценки всех отвергнутых проектов и оптимального размещения не рассчитываются;
показатели качества производственного прогноза не выдаются за универсальные
оценки всех действий агента.

## Шесть диагностик механизмов

1. Ценовой тупик закупок: доля отказов above_limit, локальные свидетели прибыльной
   покупки, парный эффект input_bid.
2. Денежное ограничение: положительная маржа и спрос, сокращение requested_output
   до финансового плана; источники концентрации денег требуют отдельного эксперимента.
3. Неподвижные запасы: доля входов на складах простаивающих фирм и доля материалов
   проектов в запасах, отдельно от реально выставленных предложений.
4. Перестройка мощностей: выпуск/план/мощность по товарам и число фирм, стартов,
   отмен. Избыточная мощность сама по себе не доказывает ошибочность инвестиции.
5. Обращение и распределение: скорость сделок, доли денег секторов, простой денег,
   зарплаты и прибыль. Сохранение общей массы не доказывает здорового обращения.
6. Восстановление: шоковый лаг, качество прогноза против naive и устойчивые локальные
   сожаления. Конечный горизонт не доказывает восстановление при любых входных данных.

## Воспроизведение

`python scripts/research_agents.py --checkpoint PATH --out NEW_DIRECTORY --variant control --months 60 --verify-state EXPECTED_FINAL`

Для вмешательств используются `--variant input_bid` и `--variant shock`. Pickle
разрешён только для собственных доверенных локальных состояний. Каталог вывода
не перезаписывается. metadata.json хранит хеш состояния, версию движка, хеш
наблюдателя, вариант, фактически выполненное число месяцев и статус. JSONL
содержит месячные макро/микрометрики, планы, попытки сделок и прогнозные ошибки.
Расчёт в памяти не заменяет проверку транзакций БД или интерфейса.

Для нового воспроизведения без файлов этого исследования:

```bash
python scripts/research_agents.py --seed 73129 --warmup 180 --months 60 --variant control --out data/research/control-73129
python scripts/research_agents.py --checkpoint data/research/control-73129/checkpoint.pickle --months 60 --variant input_bid --out data/research/input_bid-73129
python scripts/research_agents.py --checkpoint data/research/control-73129/checkpoint.pickle --months 60 --variant shock --out data/research/shock-73129
python scripts/research_agents.py --checkpoint data/research/control-73129/checkpoint.pickle --months 60 --variant cash_return --out data/research/cash_return-73129
```

Повторить для seeds 17 и 2026, затем:

```bash
python scripts/summarize_agent_research.py --directory data/research
```

Без внешнего `--verify-state` контроль автоматически дублируется ненаблюдаемым
движком и сверяет конечное состояние. Для парных вариантов повторно используется
созданный контрольный checkpoint, а не независимо созданный похожий мир.
