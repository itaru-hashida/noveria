# Приоритет доступной базовой еды

Принятое правило: покупатель сначала резервирует деньги на базовый товар,
полная месячная потребность в котором дешевле по текущей котировке с доставкой,
затем на следующий. Нужное для покупки количество уменьшается на имеющийся
запас. Сортировка использует стоимость полной потребности, как в проверенном
эксперименте, а не одну цену за тонну. При равной стоимости сохраняется порядок
товаров конфигурации; очередь покупателей по-прежнему перемешивается.

Потребности в хлебе и рыбе сохраняются. Дополнительные потребности по-прежнему
делят оставшийся бюджет пропорционально; допокупка базовой еды и пересоздание
обеспеченной остаточной книги действуют в прежнем порядке. Первоначальные
бюджетные сигналы неудовлетворённых покупателей сохраняются для цен.

Версия: `basic_budget_revision=1` в метаданных игры, исследования и диагностики.
Авторские JSON и схема БД не меняются. Старые сохранения используют правило
со следующего игрового шага. Ревизия 0 оставлена историческим исследовательским
классам; она не является игровым переключателем в интерфейсе.

## Проверка до принятия

Карта 17, сохранение месяца 1260, два опыта по 60 месяцев. За последние
30 месяцев питание 49,74% → 70,47%, у четырёх бедных стран 15,85% → 50,81%.
Хлеб населению 864,56 → 1261,54 в месяц, рыба 125,13 → 126,03.
Выпуск хлеба 873,73 → 1253,75. Преимущество наблюдалось во всех пяти годовых
окнах. Денежные и товарные инварианты выполнены, все отрасли сохраняли
положительный средний выпуск. Проверка одного мира не доказывает общий эффект
на любых картах и статистическую переносимость результата.

В конце опыта ещё расходуются некоторые запасы, поэтому стационарное
воспроизводство не доказано. Изменение принимается как проверенное улучшение
выбора покупок. Дополнительных денег, ресурсов и мощностей оно не создаёт.

Регрессии защищают порядок по полной стоимости, учёт доставки, сохранение
рыбной потребности, бюджет, допокупку, сигналы цен и диагностические балансы.
Перенос дополнительно сверяется с архивными 60 месяцами экспериментального
варианта по питанию, покупателям, рынку, производителям, трансграничным потокам,
выпуску, складам и общей кассе населения.
